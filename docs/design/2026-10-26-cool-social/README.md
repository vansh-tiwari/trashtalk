# Approved cool social design packet

These are the user-approved **2026-10-26** TrashTalk design references. Open `trashtalk-four-screens.html` locally to switch between the two desktop and two phone screens. The HTML is self-contained and needs no server or live API. Its form navigates to a sample result; it does not create real battles.

The screenshots and mockup describe composition, typography, soft lavender/sage colors, one short result roast, visual comparisons, and sharing. They are not production code. The implementation specification intentionally expands the landing to represent Codeforces, LeetCode, GitHub, CodeChef, and future providers, with only Codeforces enabled now.

Do not copy prototype limitations into the app: tiny/faint labels, hardcoded scores/roasts, prototype SVG download, mock navigation, or incomplete controls. The specification defines production behavior and accessibility corrections.

`HankenGrotesk.woff2` is the licensed Hanken Grotesk Latin font included with the supplied design reference. Preserve `FONT-LICENSE.txt` with redistributed font assets. Browser exports and PNG renderer fonts require separate format compatibility checks.
