# Changelog

All notable changes to **TrashTalk** are documented in this file.

## [2.0.0] — 2026-11

### Added
- **Next.js 15 App Router Architecture:** Complete ground-up re-engineering in TypeScript 5.7 (strict mode) with Server & Client Components.
- **Multi-Platform Live Arena:** Support for **Codeforces**, **LeetCode**, **GitHub**, and **CodeChef** 1v1 matchups and mirror roasts.
- **Deterministic 5-Axis Scoring Engine (v2.0.0):** Pure mathematical evaluation across Algorithmic Grit (30%), Contest Peak (25%), Solve Volume (20%), Recent Velocity (15%), and Topic Breadth (10%).
- **Problem Overlap & Algorithmic DNA ($P_1 \cap P_2$):** Set intersection, exclusive hard solves, and Jaccard similarity index for competitive programming platforms, plus Open Source Showcase for GitHub battles.
- **Contradiction-Guarded Roast Engine:** Local-first deterministic persona roaster with optional `@google/genai` (`gemini-3.8-flash`) integration and regional language support.
- **Server-Side Multi-Format Social Cards (`/api/og`):** Dynamic Satori + Resvg PNG card generator in `og` (`1200×630`), `square` (`1080×1080`), and `story` (`1080×1920`) formats, plus interactive `SocialShareStrip` for X, WhatsApp, Instagram Story, and link copying.
- **Launch Readiness & Accessibility:** WCAG 2.1 AA skip-to-content navigation, single-`<h1>` semantic hierarchy, JSON-LD `WebApplication` schema, canonical URLs, HTTP security headers, and automated Vitest + Playwright test suites.

## [1.0.0] — 2020-05
